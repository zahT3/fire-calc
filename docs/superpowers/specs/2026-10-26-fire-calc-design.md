## 1. 为什么做

B 站「小Lin说」视频《你需要多少钱，才能财富自由？》（BV1yUHP6rEYD，约 75 万播放）给了一个公式。看完视频的人想按自己的情况算一遍，但大多数人不会列方程。这个工具让他们 1 分钟内算出"我自己的数"，并能分享出去。

成功的样子：朋友点开链接，不需要任何说明就能算完，看到结果后愿意截图或转发。

## 2. 用户

**[用户定]** 看过视频、不懂代码的普通人和用户的朋友。他们想"照着视频试一试"，不想研究金融。

**[用户定]** 分享渠道是 X、YouTube、TikTok 等海外平台；用户会在 App 内置浏览器或复制到外部浏览器打开。不针对微信优化。

## 4. 计算模型

视频公式：

> 财富自由临界值 = 乘数 × X + K × n + M + H

| 变量 | 含义 | 单位 |
|---|---|---|
| X | 理想月开销，不含养孩子、医疗、买房；一直租房则含房租 | 元 / 月 |
| K | 每个孩子从现在起到 18 岁还需预留的钱 | 万元 |
| n | 孩子数 | 个 |
| M | 从现在起一辈子医疗费预留 | 万元 |
| H | 买房等重大开支；已有房或租房为 0 | 万元 |

- 乘数 = 12 ÷ 实际回报；实际回报 = 投资回报 − 通胀（视频的相减近似，保留）。默认 4.5% − 2% = 2.5%，乘数 480。
- 定义：不工作，本金扣除通胀后永不缩水；养老不单列，老了每月也花 X。
- 反算（"我现在有多少"）：每月可花 = (可投资资产 − K×n − M − H) × 实际回报 ÷ 12。

**口径修正（来自外部审查，已确认成立）**
- 实际回报 ≤ 0 且 X > 0 时，不输出数字，显示"这个假设下，钱总有花完的一天"，并提示调整假设。不得像原型那样偷偷把回报抬到 0.1%。
- "我现在有"问的是**可用于这份计划的可投资资产**，不含自住房；文案写明。
- K、M 问"从今天起还要留多少"，已花掉的不算。
- 个人或家庭口径由用户自选，月开销提示"两口子一起算就填两人的"。

**两个视频例子是固定回归用例**
1. X = 15,000，n = 2，K = 150，M = 150，H = 700 → 1,870 万。
2. 资产 600 万，n = 1，K = 70，M = 50，H = 0（租房）→ 每月可花 10,000 元。

## 5. 交互流程

**[用户定]** 方案 B：一屏一题，按视频顺序问四题，最后是结果页。

0. **开场页**：一句话标题、一句话说明（"按小Lin说视频的公式，4 个问题算出你的数"）、"开始"按钮、"先用视频的例子看一遍"入口、视频链接、"计算都在你的设备上，不上传数据"。
1. 月开销 X
2. 孩子：先选个数 0–4+，选 0 跳过金额
3. 医疗 M
4. 住房：已有房 / 不需要 · 一直租房（提示房租算进第 1 题）· 打算买（填金额）
5. **结果页**
6. **我现在有多少**（点亮进度 + 反算）

**输入默认值 [用户定]**
- 输入框默认**留空**，下面给参考值按钮，从低到高排列，点一下即填入。没填之前"下一步"不可用。
- 视频的例子只出现在"先用视频的例子看一遍"这条路径里；这条路径的结果页和分享图都标注"视频示例"。

**返回修改 [用户定]**
- 答过的题叠在当前卡片上方，露出一条边显示答案，点它把那张卡拉回来改。
- 结果页的明细整行可点进去改，行尾一个淡色"›"，不用"改"字。

**重新开始 [用户定]**
- 结果页提供"重新开始"：清空方格，回到第 1 题。用户自己算的，保留已填数值（方便看动效、微调重算）；从"视频示例"路径重新开始，则清空全部输入，避免视频的数混进个人结果。**[我定]**

**细节 [我定]**
- 孩子数选"4+"时出现数字输入框。
- 孩子题的参考值注明口径："从出生养到 18 岁，全国约 58 万"；已经养了几年的，按剩余年份自行估。

**结果页 [用户定]**
- 顶部：总额（大号等宽数字）+ 方格。
- 明细排成视频公式的竖式：每行"+ 颜色块 · 名称 · 小字公式字母（480X / K × n / M / H） · 金额 · ›"，最后一行"= 财富自由 总额"。
- 假设说明默认收起；展开后可调投资回报和通胀，乘数随之变化。旁边直接写"按 2% 实际回报算需要 X 万"，让用户知道视频取的是乐观端。
- 按钮：我现在有多少 · 分享图 · 复制链接 · 重新开始。

**点亮进度（新点子，用户认可"挺有意思"）**
- 填入可投资资产，按比例点亮方格，显示"已点亮 a / b 格 · p%"、还差多少、按当前假设每月约可花多少。
- 达标判断用原始金额，不用取整后的格数；未达标时百分比不显示 100%。
- 点亮用中性覆盖层表示，不暗示"孩子那一项已备足"。**[我定，采纳审查第 7 条]**

## 6. 视觉

**[用户定]** 方案 1 + 3 融合："卡片落成方格"。

- 黑底；荧光绿 #BCFF2F（日常）+ 三种柔和色：孩子 #F0A58C、医疗 #B9D3C9、住房 #E9DCC6。每张题卡的颜色 = 它在方格里的颜色。
- 数字用等宽字体（tabular-nums）。
- 方格："一格 = N 万"，面值随总额在 1、2、5 × 10ⁿ 档位中自动选，手机上不超过 200 格；换档时单位文字高亮提示。
- 答完一题，卡片碎成该项的格子飞进方格，总额数字同步滚动；减弱动效时不飞，直接出现。
- 文案极简：每屏一个问题 + 一行提示，解释收进 ⓘ。
- 视觉来源：DesignBox 里用户认可的 Web3Watch OKX 方案（黑底、荧光绿只给数据、LED 方格）、Basement Staggered Slider（错层叠卡）、Codrops 布局动效（柔和配色）。只借机制，不搬素材和品牌。
- 电脑版：左列卡片，右列大号总额 + 方格。原型里右侧方格偏小、留白过多，需要重新排。

## 8. 架构

**[我定，采纳审查第 14 条]** 一个仓库，三层：

1. **计算核心**：纯函数，无 DOM、无文案、无 I/O。输入带明确单位（统一用元存储，展示时再换算万）。负责校验、分项、总额、乘数、反算、异常状态（实际回报 ≤ 0、超范围、非法输入）、方格面值与格数分配（总格数一次分配，不让各项独立取整加出超额）。
2. **地区参数包**：每个地区一个数据文件，含币种、参考值、年份、来源、口径说明。第一版只有中国（人民币）。语言和地区分开选。
3. **展示层**：网页、命令行各一个，复用核心；文案走语言包（zh-CN、en）。

技术选择 **[我定]**：TypeScript；核心零依赖；网页用 Vite 打包成纯静态文件，不用前端框架（页面状态简单，原型已证明原生实现足够）；命令行用 Node，尽量零依赖；测试用 Vitest（核心）+ Playwright（网页交互）。许可证 MIT。

## 11. 输入校验与边界（来自外部审查，均需实现并测试）

- 区分"正在输入的文字"和"确认后的数值"；空白、非数字、负数、超范围分别提示，不按 0 计算；错误时禁用"下一步"并聚焦该输入框。
- 只接受完整的数字格式，允许千分位逗号；"1.5万"这类写法要么正确解析，要么明确提示。
- 业务范围上限（例如月开销 ≤ 1,000 万元）；所有计算结果检查是否有限；方格渲染设置硬上限。
- 竖式取整后要能加得上：分项和总额用同一精度，必要时显示一位小数或加"约"。
- 资产 = 专项预留、目标为 0 等边界给出专门文案。
- 动画期间的重复点击：一次提交锁定一次跳转；切页时清理飞行中的格子和数字动画。

## 12. 无障碍

- 每个输入框关联完整的问题文字；选择题用单选语义或 `aria-pressed`；补 `:focus-visible` 样式。
- 切题后焦点移到新题标题；结果变化只播报最终值。
- 减弱动效：CSS 和 JS 都遵守，并响应系统设置的实时变化。
