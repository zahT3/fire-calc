# FireCalc 财富自由计算器 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按小Lin说视频公式，做一个手机优先、中英双语、纯静态部署的网页计算器，以及共用同一计算核心的命令行版。

**Architecture:** 单仓库单 package。`src/core` 是零依赖纯函数（计算、校验、方格分配、格式化、链接编解码）；`src/regions` 放地区参考值；`src/i18n` 放文案；`src/web` 和 `src/cli` 两个展示层只调用核心。网页用 Vite 打成静态文件发到 GitHub Pages。

**Tech Stack:** TypeScript 5、Vite（无前端框架）、Vitest、@playwright/test、Node ≥ 20（CLI 只用 `node:util` / `node:readline`）。

**Spec:** `docs/superpowers/specs/2026-10-26-fire-calc-design.md`（下称"设计文档"）。视觉与交互参考原型 `~/Developer/_Bench/fire-video/spike/index.html`，只参考，不复制粘贴整段。

## Global Constraints

- 金额在核心里一律用**元**（number），展示层再换算"万"；回报率、通胀用小数（0.045、0.02）。
- 默认假设：投资回报 0.045，通胀 0.02，乘数 = 12 ÷ (回报 − 通胀) = 480。
- 实际回报 ≤ 0 且月开销 > 0：不输出数字，返回 `{ ok: false, reason: 'non-positive-real-return' }`。不得截断成小正数。
- 颜色：底 #000；日常 #BCFF2F；孩子 #F0A58C；医疗 #B9D3C9；住房 #E9DCC6；数字用 `font-variant-numeric: tabular-nums` 的等宽字体。
- 方格：面值从 1、2、5 × 10ⁿ 万元中选最小的、使格数 ≤ 200 的一档；无上限档位（动态扩展）。
- 输入框默认留空；未填有效值时"下一步"禁用。视频例子只出现在示例路径里，并标"视频示例 / Video example"。
- 每屏文案：一个问题 + 一行提示，其余收进 ⓘ。
- 不加统计、埋点、后端、远程字体。页面标题和元信息不得出现"原型"。
- 减弱动效：CSS 与 JS 都遵守，并监听 `prefers-reduced-motion` 的变化。
- 不搬视频画面和文案；页面与 README 注明出处并链接 `https://www.bilibili.com/video/BV1yUHP6rEYD/`。
- 对外操作（建 GitHub 仓库、push、开 Pages、发 npm）执行前逐项问用户。

## Review Focus

1. 用户粘贴 `15,000`、`1.5万`、全角数字 `１５０００` 或带空格的数：应正确解析或给出明确提示，绝不按 0 算。→ Task 2 测试。
2. 结果页里把住房从"打算买"改成"已经有房"、或把孩子数改成 0：对应分项应立刻归零，之前填的金额保留但不参与计算。→ Task 1、Task 8 测试。
3. 打开被手改过的分享链接（负数、超范围、未知字段、旧版本号）：非法字段丢弃并走正常提问，不崩溃、不显示 NaN。→ Task 5 测试。
4. 在"我现在有多少"页把回报改到 ≤ 通胀：进度区改为说明文案，不显示百分比和每月可花。→ Task 9 测试。
5. 手机浏览器返回键：在答题中按返回，应回到上一题而不是离开页面；结果页按返回回到最后一题。→ Task 6 测试。

**Interfaces:**
- Produces:
  - `type Housing = 'own' | 'rent' | 'buy'`
  - `type PartKey = 'living' | 'kids' | 'medical' | 'house'`；`const PART_KEYS: readonly PartKey[] = ['living','kids','medical','house']`
  - `interface Inputs { monthlySpend: number; kids: number; perKid: number; medical: number; housing: Housing; house: number; nominalReturn: number; inflation: number }`
  - `type Breakdown = Record<PartKey, number>`
  - `type TargetResult = { ok: true; realReturn: number; multiplier: number; parts: Breakdown; total: number } | { ok: false; reason: 'non-positive-real-return' }`
  - `computeTarget(i: Inputs, include?: readonly PartKey[]): TargetResult` —— `include` 缺省为全部；未包含的分项按 0。
  - `type AffordResult = { ok: true; monthly: number; free: number } | { ok: false; reason: 'non-positive-real-return' | 'reserves-exceed-assets' | 'reserves-equal-assets' }`
  - `monthlyAffordable(assets: number, i: Inputs): AffordResult` —— free = assets − kids×perKid − medical − (housing==='buy' ? house : 0)；monthly = free × realReturn ÷ 12。
  - `const DEFAULT_RETURN = 0.045; const DEFAULT_INFLATION = 0.02`

### Task 2: 输入解析与校验

**Files:**
- Create: `src/core/parse.ts`
- Test: `tests/core/parse.test.ts`

**Interfaces:**
- Produces:
  - `type FieldKey = 'monthlySpend' | 'kids' | 'perKid' | 'medical' | 'house' | 'assets' | 'nominalReturn' | 'inflation'`
  - `type ParseError = 'empty' | 'invalid' | 'negative' | 'too-large'`
  - `type Parsed = { ok: true; value: number } | { ok: false; error: ParseError }`
  - `parseField(field: FieldKey, text: string): Parsed` —— 返回**核心单位**（元 / 个 / 小数）。界面单位：monthlySpend 为元；perKid、medical、house、assets 为万元；kids 为个（整数）；nominalReturn、inflation 为百分数（输入 `4.5` → 0.045）。

规则：去首尾空白；全角数字和全角逗号转半角；去千分位逗号；允许尾缀 `万`（×1e4，相对元）或 `亿`（×1e8）——在"万元"字段里 `万` 表示单位本身、`亿` 为 ×1e4；其余必须整串匹配 `^\d+(\.\d+)?$`；kids 必须整数。

### Task 3: 方格分配

**Files:**
- Create: `src/core/cells.ts`
- Test: `tests/core/cells.test.ts`

**Interfaces:**
- Consumes: `Breakdown`, `PART_KEYS`（Task 1）
- Produces:
  - `pickUnit(totalYuan: number, maxCells = 200): number` —— 返回每格面值（元），取 {1,2,5}×10ⁿ × 1e4 中最小的满足 `ceil(total/unit) ≤ maxCells` 的值；total ≤ 0 返回 1e4；非有限值抛 `RangeError`。
  - `allocateCells(parts: Breakdown, unit: number): { counts: Breakdown; cells: number }` —— 先算 `cells = round(total/unit)`，再按最大余数法把 cells 分给各分项，保证 `sum(counts) === cells`。
  - `progressCells(assets: number, total: number, cells: number): { lit: number; reached: boolean; percent: number }` —— `reached = assets >= total`；`lit = reached ? cells : min(cells - 1, floor(assets/total*cells))`；`percent = reached ? 100 : min(99, floor(assets/total*100))`。

- [ ] **Step 1: 写失败测试**

```ts
  const u = pickUnit(18_700_000); expect(u).toBe(100_000);
  expect(allocateCells(parts, u)).toEqual({ cells: 187, counts: { living: 72, kids: 30, medical: 15, house: 70 } });
});
test('档位动态扩展：100 亿 → 一格 5000 万', () => expect(pickUnit(1e10)).toBe(5e7));

  const r = allocateCells({ living: 996_000, kids: 996_000, medical: 5_000, house: 3_000 }, 10_000);

});
test('差 1 万不显示全亮和 100%', () => expect(progressCells(18_690_000, 18_700_000, 187)).toEqual({ lit: 186, reached: false, percent: 99 }));
test('非有限值抛错', () => expect(() => pickUnit(Infinity)).toThrow(RangeError));
```
